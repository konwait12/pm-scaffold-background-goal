# 来源处理

本项目事实只来自 PM 在本次任务提供的材料，以及 PM 在本次对话中的明确回复。会议、口述、PPT、图片、邮件、系统数据和现有流程说明仅在由 PM 本次提供时才可使用。

如果本次工作指定了项目专属基线（例如飞书/钉钉/Notion 上的项目章程文档、决策记录或既有 PRD），通过对应 CLI 读取时，必须保留原文位置；基线原文、摘要/纪要和 AI 解读分开登记，不能把摘要当作原始证据。基线原文由 PM 在本轮明确指定并写入治理伴随文件的"项目专属基线读取记录（可选）"段。

不得使用联网搜索、通用行业知识、模型记忆、其他项目、历史产物、既有 PRD、计划、案例或 reference 示例来补充、校正、推断或验证本项目事实。现成 PRD、历史记录和案例均不属于本 skill 的输入；需要相关信息时，向 PM 询问原始材料或明确说明。除读取 PM 指定的基线外，不要把外部搜索当作本项目事实来源，除非 PM 在本轮明确授权并指定用途。

先提取材料明确说出的信息，再做归纳。对重要主张保留其页面、幻灯片、章节、时间点或说话人等位置；不需要为不同文件类型设计固定分析流程。

AI 的归纳和判断单独标明为 AI 判断，不与来源事实混写。材料没有提及，不等于该事项不存在或不重要。材料冲突或信息不足时，保留冲突或标为待确认，不自行补全。

对每条重要主张在治理伴随文件中记录：原始来源、位置、知识状态（事实、决定、假设、AI 推断、未知或冲突）以及主文档落点。

主文档参考资料只写人可读的标题、日期和位置/链接，不放 SRC 编号或追溯矩阵。

治理伴随文件记录的来源、位置和知识状态只指向本次材料、本次 PM 回复或指定会议原文；会议摘要、交接报告和本 skill 的 reference 不能冒充会议原文。
